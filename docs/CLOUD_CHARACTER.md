# Cloud Character

Cloud is the main character and guide in CloudWise.

Cloud is clearly a child, and reads **close to 11 years old**. He is warm, curious, wise, friendly, thoughtful, and always ready to learn something new.

Cloud is inspired by the founder's son. Treat this with care and respect.

Cloud should guide children through stories, reading, AI conversation, quizzes, challenges, and growth milestones. He should feel like a trusted companion, not a mascot pasted onto the interface.

Cloud's companion is Nimbus, a small cloud of light.

---

## Character direction — CURRENT

Approved 2026-08-17. **This supersedes every earlier, younger description of
Cloud anywhere in this repository.** Where an older brief says "around ten years
old", "ten-year-old" or "unmistakably ten", this section wins.

### Character Master — the reference image

> **`assets/wisdoms/three-ways-to-use-money/canvases/WIS-MONEY-001-talk-with-cloud-v1.png`**
> (1170 × 720, RGB, no alpha) is the approved **Character Master** for Cloud.

Every future Cloud illustration is matched to that file. It is not just the
anchor for one Wisdom pack — it is the reference standard for the character
across the whole product. Reproduce from it:

- the same facial identity
- the same slightly more mature child read, around 11
- the same hair silhouette
- the same body proportions
- the same calm, confident expression language
- the same premium soft 3D rendering
- the same deep navy hoodie baseline
- the same cloud emblem — **no glow required**; a clean pale mark is correct

**Do not reinterpret Cloud's face or proportions from asset to asset.** If a new
render disagrees with the Character Master on any of the eight points above,
the new render is wrong.

Cloud remains **clearly a child**. He is not aged up into a teenager. What
changed is the *read*: he now carries slightly more mature proportions and a
calmer, more self-possessed presence, because CloudWise is positioned as a
premium life companion rather than a children's game, and a baby-faced mascot
undercuts that.

### Preferred qualities

- slightly more mature proportions
- less baby-ish face and body proportions
- calm confidence
- friendly and emotionally safe
- intelligent and thoughtful presence
- premium soft 3D rendering

### Locked identity

These do not drift between illustrations:

- consistent facial identity
- consistent black hair silhouette language
- deep navy hoodie as the baseline outfit
- cloud emblem — visible on the chest; **a glow is not required**
- consistent body proportions — the mature proportions above, held steady from
  asset to asset, as rendered in the Character Master
- consistent rendering style

### Do not

- make Cloud look like a teenager or an adult
- return to very young or baby-like proportions
- change his face from image to image
- change his hair identity
- remove the cloud emblem as part of a redesign
- turn each illustration into a different character interpretation

## Outfit direction — FINAL

Cloud must keep a strong, instantly recognisable core identity across all Wisdom
illustrations. This section is the single source of truth; pack-level art
direction refers to it rather than restating it.

### Core identity — must stay consistent

Fixed in every illustration, without exception:

- same face
- same hair
- same age read and look — a child close to 11, per *Character direction —
  CURRENT* above
- same body proportions
- same friendly expression language
- same cloud emblem
- same premium soft 3D illustration style
- same deep navy core identity

### Base outfit

- Cloud's primary identity outfit is a **deep navy hoodie with the cloud
  emblem**. This is the default and the most recognisable version of him.
- **Do not remove the cloud emblem.**
- **Do not replace the navy base with a different main outfit colour.**

### Allowed variation

Cloud may have **small** outfit variations driven by weather, mood, activity or
setting. These must read as the *same child wearing context-appropriate
clothing*, never as a redesigned character.

| Context | Allowed treatment |
| --- | --- |
| Chilly weather | Navy hoodie + light jacket or zip layer |
| Rainy weather | Navy hoodie + rain layer |
| Sunny outdoor moment | Navy hoodie with lighter outer styling if needed |
| Cozy indoor moment | Navy hoodie only |
| Active or helping scene | Navy hoodie + practical casual layer |
| Calm reflective moment | Navy hoodie, simpler and cleaner styling |
| Playful moment | Subtle warmer accent details |
| Focused or serious moment | More minimal styling |

### Strict limits

- The deep navy hoodie remains the **visual foundation**.
- Keep the cloud emblem **visible whenever practical**.
- Outfit changes are **secondary, never dominant**.
- Do not give Cloud a different fashion look each time.
- Do not change hairstyle, body proportions, or overall design language.
- Do not create a different character through clothing.

### Anchor assets carry no variation

An **anchor** asset is the image a pack inherits Cloud's look from. Anchors show
the **classic deep navy hoodie only** — no extra outfit layer, no major outfit
variation — so that contextual variations elsewhere are layered onto a clean,
unambiguous baseline. `WIS-MONEY-001-TALK-WITH-CLOUD` is the approved anchor and
the Character Master; contextual outfit variation is allowed in *other*
illustrations when weather, mood, activity or setting calls for it, never here.

### Recognition test

**Cloud must still be recognisable in about one second, even when outfit
details vary.** If a reader has to work out whether it is him, the variation has
gone too far — pull it back to the base outfit.
