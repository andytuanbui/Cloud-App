# TALK-WITH-CLOUD — superseded delivery

`WIS-MONEY-001-talk-with-cloud-v01-unapproved.png` is the earlier delivery of the
pack anchor. It was never approved and never shipped.

Two things were wrong with it: Cloud was staged near the centre of the frame
(face at roughly x 0.554) instead of the left third, and the colour grade drifted
to periwinkle and royal blue. It was then also overtaken by the character
direction approved on 2026-08-17 — see `docs/CLOUD_CHARACTER.md` →
*Character direction — CURRENT* — which moved Cloud to a slightly more mature
read, around 11.

It is kept here only as a reference for what was corrected. **Nothing in the
application loads it**, and it must not be copied back into
`assets/wisdoms/three-ways-to-use-money/canvases/` — the canvas tests fail on any
PNG in that folder that the manifest does not name.

The approved anchor is `WIS-MONEY-001-talk-with-cloud-v1.png` in the pack folder.
